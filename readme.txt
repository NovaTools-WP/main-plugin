== Description ==

Empower your WordPress experience with NovaTools, the robust, React-powered foundational framework designed to seamlessly host, manage, and display dynamic addon plugins in a unified interface.

Designed for scalability and developer experience, NovaTools utilizes modern web technologies including React, TypeScript, Tailwind CSS, Vite, and Shadcn UI to deliver a seamless administrative and frontend ecosystem. Build your own WordPress ecosystem without the hassle of dealing with legacy code!

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/novatools` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Access the NovaTools menu in your WordPress admin dashboard to view and manage registered addons.

== Frequently Asked Questions ==

= Do I need other plugins for NovaTools to work? =
No, NovaTools works as a standalone core framework, but its full potential is unlocked when you install NovaTools addons (like NovaTools SEO or NovaTools Polyglot).

= Is it developer-friendly? =
Absolutely! NovaTools exposes a straightforward API for registering PHP routes and React components, letting you focus on building features rather than infrastructure.
